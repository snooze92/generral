# Contributing

Thanks for your interest! Generral is still being built against its
[specification](docs/specs/README.md) and **isn't accepting outside contributions yet**: issues,
pull requests and discussions are switched off for now. They will open once the first usable
release (v0.1, see the [roadmap](docs/specs/13-roadmap.md)) is out.

Security problems can already be reported privately; see [SECURITY.md](SECURITY.md).

Generral is licensed under the GPL-3.0-or-later ([LICENSE](LICENSE)). Once contributions open,
contributions will be accepted under the same licence.
