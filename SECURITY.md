# Security policy

Generral is in early development and has no stable release yet. Fixes go into `main` and the
`develop` container image.

## Reporting a vulnerability

Please **do not** open a public issue or pull request. Use GitHub's
[private vulnerability reporting](https://github.com/snooze92/generral/security/advisories/new)
instead. Include the affected version or commit, how to reproduce, and the impact you expect.

You should get an answer within a week. Once a fix is available, the advisory is published with
credit to the reporter unless you'd rather stay anonymous.
